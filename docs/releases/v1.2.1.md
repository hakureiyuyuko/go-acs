# v1.2.1 —— 修一处界面文案的格式化错误

**只修显示，程序逻辑没动。**

## 修了什么

终端弹窗的标题写成「主机 %!s(int=5) 台 · 子设备 %!s(int=6) 台 · 共 11 台」——
中英双语改造时，那句文案的模板里把**整数**值喂给了 `%s`（Go 的 `Sprintf` 于是把
`%!s(int=5)` 原样打了出来）。同一个坑的另一处（FTTR 那行，值是字符串）当时是对的，
所以只有弹窗这一处露了出来。

## 顺带加了道防线

`verify-s1.sh` 新增第 37c 节：把列表页、设备详情页、无线编辑页、设置页在中/英两种语言下
都渲染一遍，**只要页面上出现 `%!(…)` 这类格式化错误标记就报失败**（8 条断言）。
这类错只有在真渲染时才现形，之前那套断言（英文页面无中文残留）抓不到它。

## 升级

已经装了 v1.2.0 的机器直接覆盖即可（没有数据库结构变化）：

```bash
tar xzf acs-1.2.1-linux-amd64.tar.gz && cd acs-1.2.1-linux-amd64
sudo ./install.sh     # 或 sudo ./update.sh
```
