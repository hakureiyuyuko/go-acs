# v1.1.0 —— 在线状态按设备周期判定 + 界面三态与筛选

这一版改了**在线状态的判定方式**（含一次数据库自动迁移），并给离线设备加了操作限制。

## 在线判定：不再固定 10 分钟，改成按设备自己的上报周期

TR-069 里设备断电**不会通知 ACS**（设备只在有会话时说话），在线状态本来就只能靠
「多久没动静」推断。原来写死 10 分钟，对 120 秒周期的设备太钝、对 1 小时周期的又太急。
现在跟设备上报的 `PeriodicInformInterval` 挂钩：

```
最后一次上报 + 上报周期×2          → 开始主动探测：发 Connection Request
  ├─ 最多探 3 次（默认间隔 15s）
  ├─ 有一次连上 → 设备还活着：保持在线
  └─ 3 次都连不上 + 再等 30s      → 标记离线
设备没上报周期信息 / 关掉探测       → 退回 -offline-after（默认 10 分钟）纯超时
没有 ConnectionRequestURL          → 没法探，超期直接判离线
```

以 120 秒周期的设备为例：约 4 分钟开始探测，**6 分钟左右判离线**（原来要 10 分钟以上）。
探测并发发出，一批设备同时掉线也不会拖慢巡检。

新配置项（默认值就是上面这套，都能改）：
`-offline-probe`、`-offline-probe-factor`、`-offline-probe-attempts`、`-offline-probe-interval`、
`-offline-probe-grace`、`-offline-probe-max`、`-offline-check-interval`。

## 界面上看得见状态

- 设备状态三态：**在线** / **探测中**（超期了、正在探测）/ **离线**
- 概览「在线」卡片补一行「N 台正在探测」；设备详情页写明「超期未上报，已主动探测 N 次 + 最近一次时间」
- 首页新增**在线 / 离线 / 探测中**筛选（`?state=`，可跟搜索叠加，地址随便分享）
- **离线设备的操作按钮变灰**：重新获取、立即唤醒、重启、诊断都禁用（并说明原因）；
  删除设备仍可用（纯本地操作），备注也照旧可改

## 升级注意

- **数据库会自动迁移**（新增 `devices.probe_count` / `probe_at` 两列，`user_version` 2→4），
  设备数据、参数、任务、上报记录都不动。升级前建议照惯例备份一下 `acs.db`。
- 行为变化：设备被判离线会比以前**快**（按周期算）；`-offline-probe false` 可以退回旧行为。

## 升级

```bash
tar xzf acs-1.1.0-linux-amd64.tar.gz && cd acs-1.1.0-linux-amd64
sudo ./install.sh     # 原地升级，保留数据库与 /etc/default/acs
# 或者
sudo ./update.sh      # 从 GitHub 拉最新版（校验 SHA256、备份、失败自动回滚）
```
