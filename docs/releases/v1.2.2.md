# v1.2.2 —— 无线概况自动刷新 + 面板不再吃浏览器缓存

两个都是用户实测反馈出来的问题，**没有数据库结构变化**。

## 1. 无线 / 终端概况到期自动刷刷新

**现象**：详情页和终端弹窗里那个「采集 23:13:12」一直不动，只有手动点「采集 WiFi / 重新采集」
才会更新。

**原因**：无线概况（SSID、开关、信道、加密、关联终端）不是设备在 Inform 里主动报的，得 ACS
主动去读；原来只在**首次纳管 / `0 BOOTSTRAP`** 时读一次，之后就没有任何机制再去读 ——
参数表的 `updated_at` 不变，界面上的「采集」时间自然就冻在纳管那一刻。

**改法**：新增 `-auto-refresh-wifi`（env `ACS_AUTO_REFRESH_WIFI`，默认 **10 分钟**，
`0` = 只在首次纳管时采一次，即旧行为）。每次设备上报时看一眼该设备无线参数最近一次写入时间
（与界面显示的是**同一个来源**，不会出现「界面说 3 分钟前、实际 10 分钟前」），到期就把采集任务
再排一次 —— 顺带把终端主机名那批参数也带上。任务在本次会话里下发，设备上报后界面很快刷新。

## 2. 面板页面不再被浏览器缓存

**现象**：改了界面/参数，打开面板看着还是旧的，容易误判成「没生效」。

**改法**：面板 HTML 一律 `Cache-Control: no-store`；`/static/` 用 `no-cache`（每次回源确认），
改了 `app.js` / `style.css` 刷新就能用上。

## 升级

```bash
tar xzf acs-1.2.2-linux-amd64.tar.gz && cd acs-1.2.2-linux-amd64
sudo ./install.sh     # 或 sudo ./update.sh
```

升级后如果浏览器里还留着旧页面，强刷一次（Ctrl+F5）即可 —— 之后不会再被缓存。
