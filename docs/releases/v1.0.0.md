# v1.0.0 —— 轻量 TR-069 ACS 首个发布

> **这个版本的 `update.sh` 有 bug，请用 v1.0.1 的包**：它去 GitHub 抠下载地址时正则贪婪，
> 会把 `SHA256SUMS` 的地址当成 tar.gz 的地址（校验闸拦住了，不会装上坏东西，但升不了级）。
> 已经装过的机器，把 v1.0.1 的包解开、用里面的 `update.sh` 或者直接 `sudo ./install.sh` 即可。

单二进制、零外部中间件的 TR-069/CWMP ACS，用来管一批光猫 / FTTR 主机：
**纳管 → 看信息 → 改配置 → 诊断 → 子设备与终端管理**。

## 下载

| 平台 | 安装包 |
|---|---|
| Linux x86_64 | `acs-1.0.0-linux-amd64.tar.gz` |
| Linux ARM64 | `acs-1.0.0-linux-arm64.tar.gz` |

校验和在同日的 `SHA256SUMS` 里；`update.sh` 会自动校验。

## 安装

```bash
tar xzf acs-1.0.0-linux-amd64.tar.gz
cd acs-1.0.0-linux-amd64
sudo ./install.sh
```

装完打印面板地址与要填进光猫的 ACS URL。想把面板挪到独立端口、顺便设面板账号密码：

```bash
sudo ./install.sh --web-listen :8080 --web-user admin --web-pass '改成你自己的'
```

默认落点在包内 `README.md` 里列全了（主程序 `/usr/local/bin/acs`、数据 `/var/lib/acs`、
配置 `/etc/default/acs`、systemd 服务 `acs`）。

## 升级与卸载

```bash
sudo ./update.sh          # 从 GitHub 拉新版：校验 SHA256 → 停服务 → 备份 → 换新 → 健康检查，起不来自动回滚
sudo ./update.sh --check  # 只看有没有新版本
sudo ./uninstall.sh       # 拆服务与程序，保留数据；--purge 连数据一起删
```

## 这个版本有什么

- **协议**：Inform / GetParameterValues / GetParameterNames / SetParameterValues / GetRPCMethods /
  Reboot / IPPingDiagnostics / Connection Request（含 HTTP Digest），任务队列持久化
- **面板**：设备概览与搜索、设备详情（基本信息、WAN 连接、无线概况、参数、任务与上报记录）、
  FTTR 子设备与关联终端（按主机/子机分组、信号强度）、设置页（ACS 与面板双监听、面板账号密码）
- **运维**：一键唤醒、重启设备、删除设备、备注、任务与上报记录保留上限
- **部署**：单文件静态二进制 + 一个 SQLite 文件，没有 Redis / MySQL / 消息队列
